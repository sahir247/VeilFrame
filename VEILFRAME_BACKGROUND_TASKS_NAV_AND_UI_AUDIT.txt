4. SECOND DEEPER & BROADER ARCHITECTURAL PLAN
--------------------------------------------------------------------------------
1. Background Task State Synchronization Across the Subsystem:
   - What happens if the service completes while the user is outside the app?
     `activeJob` state becomes `COMPLETED`. When the user taps the completion notification or re-opens Motion Lab, the controller must recognize the completed job, find the output file, and display the result card with "Save to Gallery".
   - What about `VideoStudio` and `UpscaleForegroundService`?
     Apply the same notification pending intent pattern across all foreground services in the app so tapping any active processing notification returns the user to the active tool.

2. Universal Touch Handling & Multi-Window / Dialog Interactions:
   - In `dispatchTouchEvent`, ensure views inside modal bottom sheets (like `SharedSourcePickerSheet`) or search text boxes inside fragments aren't abruptly unfocused if clicking inside internal scrollable containers or dropdown suggestions.
   - Use `v.getGlobalVisibleRect(outRect)` with raw screen coordinates to prevent coordinate transform errors.

3. Search Ranking & Token Matching Architecture:
   - If someone types "re", it should match words starting with "re" (e.g., "Remover", "Remove").
   - Tokenize query by space: `val tokens = query.split("\\s+".toRegex()).filter { it.isNotEmpty() }`.
   - A route matches if for every token, either:
     * A word in the title starts with or contains the token.
     * An alias starts with or contains the token.
     * Description contains the token.
   - If `query.isNotEmpty()`, ignore category chip constraints (or automatically select `chipCategoryAll`) to prevent hidden matching tools.

4. Orientation & Navigation Bar Geometry on Foldable / Dual-Screen Devices:
   - On devices like OnePlus Open or Pixel Fold, unfolding the device changes `smallestScreenWidthDp` dynamically at runtime.
   - Using `smallestScreenWidthDp >= 600` cleanly distinguishes between:
     * Folded mode (phone form factor, width ~390dp, height ~850dp) -> `BottomNavigationView` in portrait and landscape.
     * Unfolded mode (tablet form factor, width ~800dp, height ~800dp, `sw >= 600`) -> `NavigationRailView` on the left.
   - This avoids any 180° jumping or layout snapping when rotating phones in landscape.

11. Deep Technical Explanation: `warp_pack8.comp` in RIFE
   - Work of `warp_pack8.comp`:
     In upstream `nihui/rife-ncnn-vulkan`, `warp_pack8.comp` is a Vulkan GLSL compute shader designed for backwards optical-flow warping (grid sampling) of 8-channel packed tensor arrays (`afpvec8` SIMD data layouts) using Vulkan subgroup and image sampling extensions.
   - Why mobile NCNN RIFE skips it:
     1. In standard RIFE (RIFE v2/v3/v4), image warping operations operate strictly on standard 3-channel (RGB) video frames.
     2. NCNN packing for 3-channel RGB is either `pack1` (unpacked single channels) or `pack4` (RGBA aligned/padded). A 3-channel image tensor NEVER has a channel count divisible by 8, so NCNN's internal dispatch pipeline NEVER dispatches the `pack8` pipeline for image warping.
     3. Furthermore, mobile GPU GLSL compilers (Qualcomm Adreno, ARM Mali, PowerVR) lack native hardware vector types for 8-wide float vectors (`afpvec8`), causing shader compilation errors or fallbacks if forced.
   - Effect on results:
     Omitting `warp_pack8.comp` has ZERO mathematical or visual effect on output frames. The 3-channel RGB frame synthesis path strictly executes `warp.comp` (`pack1`) or `warp_pack4.comp` (`pack4`), which produce bit-for-bit identical interpolated video frames.
   - Evidence: [SOURCE VERIFIED]
